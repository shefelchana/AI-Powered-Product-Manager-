# Разбор колоды слов

Колода живёт в приложении, доступ к ней — через MCP-сервер `vocab`.

## Порядок

1. `list_words` с `without_definition: true` — взять **не больше 10** слов за прогон
2. Для каждого слова — `check_sources`
3. Дальше строго по вердикту:

| Вердикт | Что делать |
|---|---|
| **источники расходятся** | Не записывать. В отчёт как спорное, с обоими значениями |
| **ответила только Академия и предлагает варианты** | Не выбирать. В отчёт |
| **не противоречат, у Академии несколько вариантов** | Записать по ответившему источнику, в отчёте отметить неоднозначность |
| **не противоречат** и ответила Академия однозначно | `lookup_in_academy` — справка сохранится сама, с настоящей подписью |
| **не противоречат**, ответил Pealim | `lookup_in_pealim` — сохранится значение, корень и биньян, с настоящей подписью. **Не** писать своё: у слова есть источник |
| **не противоречат**, ответил только Викисловарь | `set_definition` по его значению |
| **нет данных ни в одном источнике** | Написать своё объяснение и записать через `set_definition` |
| **ни один источник не ответил** (сбой сети) | **Ничего не писать.** Это отсутствие проверки, а не отсутствие данных. В отчёт |
| **сравнить не с чем / нечем** | Записать по единственному ответившему, в отчёте отметить, что сверки не было |
| в вердикте есть «недоступны: …» | Можно записывать, но в отчёте назвать, какой источник молчал |
| в ответе есть строка **«Урок (преподаватель): …»** | Это четвёртый источник, совещательный. Его не сравнивают со словарями машинно (он по-русски). Записывать словарное значение можно; если оно по смыслу расходится со словами преподавателя — в отчёт как «расхождение с преподавателем», без выбора. Значение урока **не перезаписывать** и **не перезаписывать им** словарное |

4. Записать отчёт

## Как писать своё объяснение

- На языке слова, **одна строка**, простыми словами
- Плюс **один пример употребления**
- Без этимологии, спряжений и грамматических таблиц
- Если слово многозначное — то значение, которое подходит к учёбе на MBA,
  и пометка, что есть другие
- Если Pealim дал транслитерацию — добавить её: она показывает звучание

## Запреты

- **Не выдумывать.** Не уверен — оставить пустым и написать в отчёт
- **Не трогать слова, у которых объяснение уже есть.** Даже если своё кажется лучше
- **Не выбирать** между вариантами Академии и при расхождении источников
- **Не больше 10 слов за прогон.** Один сбой не должен испортить всю колоду
- **Не писать своё там, где ответил источник.** Метка «сгенерировано, проверь»
  предназначена словам, которых не знает никто, — если ею подписать то, что
  знает Pealim, Анна будет перепроверять лишнее и перестанет доверять метке
- **Корень не вычислять.** Он берётся только из словаря. В иврите выделение
  корня нетривиально, а выдуманный корень свяжет между собой неродственные слова
- **Значение преподавателя (`lessonNote`) — не трогать.** Оно пришло с урока и лежит отдельно от
  словарного объяснения; ни `set_definition`, ни справки словарей его не заменяют. Расхождение
  с преподавателем — совет посмотреть, не запрет записывать
- **Не путать «источник недоступен» с «данных нет».** Первое — это отсутствие
  проверки: писать нельзя. Второе — проверка прошла и ничего не нашла

## Почему запреты именно такие

Источники ошибаются. У слова `לזרז` Академия отдавала «catalyze» из словаря
органической химии, хотя слово значит «торопить». Молча записанное правдоподобное,
но неверное объяснение приводит к неправильно выученному слову — это дороже, чем
пустая карточка. Поэтому сомнительное помечается, а не принимается.

## Отчёт

Файл `~/Documents/AIPPM/vocab-reports/YYYY-MM-DD.md` — если папки нет, создать. В нём:

- что разобрано и из какого источника
- что помечено спорным и почему — с обоими значениями, чтобы Анна рассудила
- что пропущено и по какой причине
- какие источники были недоступны
- где словарь разошёлся с преподавателем — оба значения рядом, Анна рассудит

Без отчёта нельзя понять, что агент сделал в боевой базе.
